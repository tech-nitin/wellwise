# Drilling Well Explorer — Phase 5

Phase 5 is a visual-fidelity pass based on the supplied Drilling Well Construction reference. It adds a 9-shot cinematic construction sequence, casing couplings, BHA stabilizer/cutter details, casing shoe, layered stratal bands, reservoir halo, inspection close-up, and dashboard polish.

Run:

```powershell
npm install
npm run dev
```

Open the Vite localhost URL. The project uses Three.js + Vite + GSAP and is self-contained; no external 3D asset download is required for this phase.
