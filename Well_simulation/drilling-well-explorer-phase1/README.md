# Drilling Well Construction Explorer — Phase 1

Starter recreation of the supplied drilling visualization reference.

## Run
Open a terminal in this folder:

```powershell
npm install
npm run dev
```

Then open the localhost URL printed by Vite.

## Included
- Three.js 3D geological layers
- Directional wellbore and casing
- Drill string + bit
- Simple surface rig
- Orbit camera
- Engineering dashboard UI
- Stage switching and GSAP camera/model transitions
- Metrics, opacity control, and timeline
